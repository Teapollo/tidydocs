Tidy Docs - Google Docs Editor Add-on

Clean, Format, and Organize Your Google Docs

A fast, 100% free, client-side formatting & cleanup engine for Google Docs. Merges broken PDF lines, formats AI markdown, and sorts bibliographies.

Install on Google Workspace Marketplace

Key Features

1. Smart Clean Document

  • PDF Line-Wrap Merger: Rejoins broken mid-sentence lines from copied multi-column PDF excerpts without gluing headings, lists, or reference citations together.
  • AI Markdown Converter: Converts ChatGPT, Claude, and Gemini markdown artifacts (**bold**, *italics*, ### Headings, and `code` pills) into native Google Docs styles.
  • Non-Destructive Case Sanitizer: Normalizes lowercase sentence beginnings, fixes Shift-slips (THe → the), and capitalizes I contractions while strictly protecting properly capitalized proper nouns (United States, Google, HuggingFace, etc.).
  • Spacing Sanitizer: Strips hidden Unicode zero-width characters and collapses redundant duplicate whitespace.

2. Paragraph & Outline Sorter

  • Alphabetical (A to Z and Z to A): In-place sorting of highlighted paragraphs, table cell contents, and numbered outlines.
  • Academic Surname Sort: Alphabetizes bibliography and reference lists by author last name while preserving italics and hyperlinks.
  • Natural Numeric Ordering: Accurately sorts numbered items (Chapter 1, Chapter 2, Chapter 10).
  • Hierarchical Nested Lists: Reorders parent list items while keeping nested child sub-bullets anchored to their respective parents.

3. Numbered Section Organizer

  • Automatically detects out-of-order multi-paragraph sections (e.g. 2.3, 2.1, 2.2) and reorganizes them along with their child paragraphs into sequential order (2.1 → 2.2 → 2.3).
  • Keeps terminal sections (References, Appendices, Acknowledgments) anchored in place.

Privacy Policy

Last Updated: October 2026 • Developer: Alan Nguyen • Contact: alannguyen1306@gmail.com

1. Plain-English Summary

TidyDocs is a 100% client-side Google Docs add-on. It runs entirely inside your browser session using Google Apps Script V8. We operate zero external database servers, collect zero personal data, and never transmit your document text across the internet.

2. Permissions & Data Usage

TidyDocs requests only the minimum permissions necessary to function:

  • https://www.googleapis.com/auth/documents.currentonly: Used strictly to read and format text in the single active document currently open in front of you. It cannot access any other file in your Google Drive.
  • https://www.googleapis.com/auth/script.container.ui: Used strictly to display the TidyDocs sidebar and settings interface inside Google Docs.

3. Data Storage & Retention

  • Zero Document Retention: Your text is processed ephemerally in your browser's sandboxed memory during operations (sorting, cleaning, casing) and is never saved, cached, or logged.
  • Local Settings: User preferences (such as your chosen sort order) are saved strictly in your local browser sandbox (localStorage / Google Apps Script PropertiesService).

4. Google Limited Use Disclosure

TidyDocs' use and transfer of information received from Google APIs adhere strictly to the Google API Services User Data Policy, including the Limited Use requirements. Document content is never transferred to third parties, never used for advertising, and never used to train machine learning models.

If you have any questions or feedback, contact Alan Nguyen at alannguyen1306@gmail.com or open an issue on GitHub.
