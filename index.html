Google Docs Editor Add-on

Clean, Format, and Organize Your Google Docs in One Click

A lightweight, 100% free client-side utility suite running on Google Apps Script V8. Merges broken PDF line wraps, formats AI markdown, and sorts paragraphs with zero server tracking.

Install on Google Workspace Marketplace

Core Features

1. Smart Clean Document

  • PDF Line-Wrap Reconstruction: Merges broken lines from copied academic 2-column PDFs without joining headings or citations.
  • AI Markdown Formatting: Converts raw ChatGPT/Claude tags (**bold**, *italics*, ### Headings, and `code`) into native Docs styling.
  • Non-Destructive Case Sanitization: Fixes sentence beginnings and Shift-slips (THe) while preserving proper nouns (United States, Alan Nguyen, OpenCV).

2. Paragraph & Outline Sorting

  • Alphabetical (A to Z and Z to A): Sorts paragraphs, lists, and table cells in place.
  • Academic Surname Sort: Sorts bibliography lists by author last name while keeping journal italics and DOIs intact.
  • Section Ordering: Reorders numbered parts (e.g., 2.3, 2.1, 2.2) along with their body prose into sequential order.

Privacy Policy

Last Updated: October 28, 2026

TidyDocs runs 100% client-side inside your Google Docs V8 session. We do not operate external database servers, we do not store your data, and we never transmit document content outside of Google Workspace.

Requested OAuth Scopes

  • https://www.googleapis.com/auth/documents.currentonly: Used strictly to read and format text in the single active document where you opened TidyDocs.
  • https://www.googleapis.com/auth/script.container.ui: Used strictly to display the TidyDocs sidebar and settings interface within Google Docs.

Data Handling

TidyDocs adheres strictly to the Google API Services User Data Policy, including Limited Use requirements. Your text is processed purely in ephemeral browser memory and is never used for advertising, telemetry, or machine learning training.
